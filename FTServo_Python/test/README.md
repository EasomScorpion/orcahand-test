# 舵机监控控制台 - 使用说明

## 简介

这是一个基于 Python 的舵机监控控制台，提供实时数据显示、趋势图表、舵机控制等功能。

## 功能特点

- **📊 实时监控**: 实时显示所有在线舵机的位置、速度、负载、电压、温度等参数
- **📈 趋势图表**: 历史数据曲线图，支持多种数据类型的趋势分析
- **🎮 舵机控制**: 位置移动、速度设置、加速度调节等控制功能
- **📝 系统日志**: 完整的操作日志和错误记录
- **🎨 深色主题**: 专业的深色界面，适合长时间使用

## 环境要求

### 硬件要求
- 串口设备（USB转串口模块）
- FT舵机（SMS_STS系列）
- Windows/Linux/Mac系统

### 软件依赖
- Python 3.7+
- 必需的Python库：
  ```bash
  pip install matplotlib
  ```

## 安装步骤

### 1. 安装依赖库
```bash
pip install matplotlib
```

### 2. 配置串口参数
编辑 `servo_monitor.py` 文件中的配置部分：

```python
# ==================== 配置 ====================
PORT_NAME = 'COM3'         # Windows: COM1, COM2, COM3...
                           # Linux: /dev/ttyUSB0
                           # Mac: /dev/tty.usbserial-*
BAUD_RATE = 1000000        # 波特率
SCAN_ID_START = 1          # 扫描起始ID
SCAN_ID_END = 20           # 扫描结束ID
```

### 3. 运行程序
```bash
cd test
python servo_monitor.py
```

## 使用指南

### 界面布局

程序包含4个主要页面：

#### 1. 📊 实时监控页面
- 显示所有在线舵机的实时状态
- 每个舵机显示位置、速度、负载、电压、温度
- 自动滚动查看大量舵机

#### 2. 📈 趋势图表页面
- 选择要监控的舵机ID
- 选择数据类型（位置/速度/负载/电压/温度）
- 显示历史数据曲线图
- 支持图表缩放和保存

#### 3. 🎮 舵机控制页面
- **位置控制**: 设置舵机移动到指定位置（0-4095）
- **速度控制**: 设置运行速度（0-2400）
- **加速度控制**: 设置加速度（0-50）
- 实时反馈操作结果

#### 4. 📝 系统日志页面
- 显示所有操作日志
- 不同级别的日志用颜色区分
- 支持日志搜索和复制

### 操作说明

#### 扫描舵机
程序启动时自动扫描配置的ID范围内的所有舵机。

#### 控制舵机
1. 在"舵机控制"页面选择要控制的舵机ID
2. 输入目标参数（位置、速度、加速度）
3. 点击相应按钮执行控制命令
4. 在日志页面查看操作结果

#### 查看趋势
1. 在"趋势图表"页面选择舵机ID
2. 选择要查看的数据类型
3. 图表会自动更新显示最近100个数据点

## 常见问题

### 1. 串口打开失败
- 检查串口是否被其他程序占用
- 确认串口名称是否正确
- 尝试重新插拔USB转串口模块

### 2. 扫描不到舵机
- 检查串口连接是否正确
- 确认波特率设置是否匹配
- 检查舵机供电是否正常

### 3. 控制命令失败
- 检查舵机ID是否正确
- 确认参数范围是否在有效范围内
- 查看系统日志获取详细错误信息

### 4. 图表不显示
- 确认matplotlib库已正确安装
- 检查是否有数据更新
- 尝试重新选择舵机和数据类型

# 舵机控制台 (servo_console.py) - 使用说明

> 专为本项目定制：**17 个 STS3215 舵机的日常调试控制台**，含硬底线安全参数 + 单舵机滑块控制 + 参数浏览器 + 紧急停止。

## 功能

### 🎮 控制台 Tab
- **串口连接**: 选择 COM 口 + 波特率（默认 1Mbps）
- **应用安全底线**: 一键写入 `MAX_TORQUE=100`、`PROTECT_TORQUE=20`、`OVERLOAD_TORQUE=20`、`PROTECT_TIME=20`（写到 EPROM，自动 unLock/lock）
- **复位到 2048**: 17 舵机同步回到中位（速度 100、加速度 10，出厂保守默认）
- **单舵机滑块**: 下拉框选舵机，滑块范围自动取该舵机的 [MIN_ANGLE, MAX_ANGLE]（来自 `参数/N.xdat`，即机械手物理极限）
  - 切换舵机时，滑块初值 = 该舵机的当前 PresentPos
  - 拖动过程中**不发送**串口命令，**松手才发一次** WritePosEx
  - 越界时会弹错误并自动回弹到合法中位
- **紧急停止** ⚠: 按下立即关闭所有扭矩（广播）+ 冻结所有写入；再次点击恢复控制

### 📋 参数浏览器 Tab
复刻飞特官方调试软件的"参数列表"功能：
- 表格列出全部 **28 个 EPROM 字段 + 14 个 SRAM 字段**（名称/地址/当前值/默认值/读写/单位/说明）
- 「⟳ 从舵机刷新」: 一次性读回所有寄存器的实际值
- 「💾 保存选中项到 EPROM」: 把选中行的当前值写到舵机 EPROM（自动 unLock/lock）
- 「📤 导出当前舵机参数到 .xdat 文件…」: 弹文件保存对话框，自选目标路径和文件名，用 `xdat_tool.write_xdat` 写出

### 🎭 动作库 Tab（石头剪刀布等预设姿态）
用于调试和保存机械手的预设姿态，是石头剪刀布游戏的核心：

- **「📸 记录当前 17 舵机位置」**: 用 GroupSyncRead 一次性读取全部 17 舵机的 PresentPos，按输入的名称保存为一条姿态
- **可折叠的姿态列表**: 显示所有已保存姿态（"石头    (17 个舵机, 2024-01-15 14:30:25)"）
- **「▶ 到达选中姿态」**: 用 RegWritePosEx + RegAction 同步下发，17 舵机严格同时启动
- **「✏ 重命名」**: 弹输入对话框改名
- **「🗑 删除选中」**: 删除姿态（带确认）
- **「💾 导出姿态库到文件…」** / **「📂 从文件导入姿态库…」**: JSON 文件备份/恢复
- **双击列表项**: 快速到达该姿态
- **自动持久化**: 所有改动立即写入 `test/saved_poses.json`，重启程序不丢失

### ✊ 石头剪刀布 Tab
跟笔记本摄像头对战！

- 复用 `gesture_recognition/gesture_rps.py` 的 MediaPipe + RPS 分类器
- **「🎬 启动游戏」**: 打开摄像头 + 后台线程实时识别；「⏹ 停止游戏」: 关闭线程
- **摄像头画面**: 实时显示（10 fps 缩放显示）
- **状态机**:
  - `IDLE`      — 等待手出现
  - `DETECTING` — 识别中（手已出现，正在跟踪）
  - `EXECUTING` — 派发姿态中（舵机在动）
  - `RESETTING` — 2 秒无手势 → 自动复位到 2048
- **持续 1 秒**才确认手势（防抖）
- **胜出映射**: 可在右侧下拉框配置（你出石头 → 机械手出布，包住你的石头；等等）
- **执行顺序**: 确认 → 派发 winning pose → 等所有舵机 `ReadMoving==0` → 才允许识别下一轮
- **2 秒超时**: 没有任何手势识别 → 自动复位到 2048
- **战绩计数**: 每一轮自动 +1（机械手胜）
- **日志**: 显示在右侧深色面板

> ⚠️ 此 Tab 需要先安装摄像头依赖: `pip install -r gesture_recognition/requirements.txt`
> 依赖缺失时点启动会弹错误，不会让主 UI 崩溃。

## 安全底线（不可被任何上层功能覆盖）

实现：所有写入必须经过 `ServoSafetyLayer`，UI 不直接持有 `sms_sts`：

| 层级 | 检查 |
|---|---|
| 1 | 急停标志 `_emergency_stopped`：为 True 时**所有写入抛异常** |
| 2 | 角度限位：每个舵机的 [min_angle, max_angle] 取自 `参数/N.xdat`，滑块 setRange + 写指令前再校验 |
| 3 | 速度/加速度上限：speed ∈ [0, 2400], acc ∈ [0, 254] |
| 4 | EPROM 写入：自动 `unLockEprom → write → LockEprom` 三步，失败时 finally 锁回 |
| 5 | 急停广播：向 `BROADCAST_ID` 写 `TORQUE_ENABLE=0` 一次关闭所有舵机扭矩 |

## 启动

### 方式 1：使用启动脚本（推荐）

**Windows**:
```cmd
cd test
run_console.bat
```

**Linux / macOS**:
```bash
cd test
./run_console.sh
```

启动脚本会自动检查 Python 和 PyQt5/pyserial，缺哪个就 `pip install` 哪个。

### 方式 2：手动启动

```bash
pip install -r test/requirements.txt          # PyQt5 + pyserial + matplotlib
pip install -r gesture_recognition/requirements.txt   # 可选：opencv-python + mediapipe（用于 ✊ 石头剪刀布）
cd test
python servo_console.py
```

> 如果不装摄像头依赖，主 UI 仍可正常工作，只是「✊ 石头剪刀布」Tab 会提示缺包。

## 配置

### 关节 ↔ 舵机 ID 映射（可选）

创建 `test/servo_joints.json`（UTF-8 编码），格式：

```json
{
  "1":  "拇指根部",
  "2":  "拇指中部",
  "3":  "食指根部",
  ...
  "17": "手腕旋转"
}
```

存在时下拉框会显示 "ID 1 — 拇指根部"；不存在则只显示 "ID 1"。

### 串口/参数文件位置

- 参数文件默认在 `../参数/N.xdat`（相对 `test/`），由 `xdat_tool.REGISTERS` 表驱动
- 串口名直接在下拉框里编辑输入

## 使用流程

1. 启动 → 加载 17 个 xdat → 下拉框填充 ID 1~17
2. 选 COM 口 → 点「连接」 → 状态变绿
3. 点「应用安全底线」 → 17 个舵机 EPROM 写入 50/20/20/20
4. 点「复位到 2048」 → 所有舵机同步回中位
5. 切换到任一舵机 → 拖动滑块 → 松手 → 该舵机转到目标位置
6. 切到「📋 参数浏览器」Tab → 「⟳ 从舵机刷新」 → 看/改/保存参数 → 「📤 导出到 .xdat」备份
7. 切到「🎭 动作库」Tab → 用滑块调好"石头"姿态 → 输入名字 → 「📸 记录」
8. 同样保存"剪刀"、"布"等姿态
9. 切到「✊ 石头剪刀布」Tab → 「🎬 启动游戏」 → 出拳！机械手自动用胜出姿态回应你
10. 紧急情况按「⚠ 紧急停止」 → 所有扭矩切断、所有操作冻结

## 紧急情况

- **机械手失控**: 按「⚠ 紧急停止」按钮（红色），扭矩立即切断
- **恢复**: 再次点击按钮（变橙色"✅ 恢复控制"），但扭矩需要到参数浏览器把 `力矩输出` 写 1 才会重新生效
- **想完全退出**: 关窗口 → polling 线程自动退出，串口自动关闭
